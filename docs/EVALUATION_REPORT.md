# FlashVTG DQ-CGP (v3) Semantic Novelty × Event Existence 完整评估报告

**实验日期**：2026-10-01 至 2026-10-02  
**测试方法**：FlashVTG DQ-CGP (v3, sparse top-4 routing + relation loss, 严格训练从头收敛 100 轮)  
**基准对照**：FlashVTG-GMR Baseline (同种子 3407, 100 轮)  
**数据集**：Charades-STA 衍生 semantic novelty × event existence v2 (五独立划分)  
**执行协议**：严格遵循 `plan.md`，训练仅使用 $S^+ / S^-$，选模严格依赖 seen validation $(R1@0.7 + R1@0.5)/2$，测试评测涵盖 $S^+ / S^- / U^+ / U^-$。

## 1. 核心问题回答 (Plan.md Section 2 & 18)

> **核心实验问题**：把现有的 DQ-CGP 方法应用到这个新的数据集上以后，能不能减缓 FlashVTG-GMR 从 seen semantics 到 unseen semantics 的性能退化？

**评估结论**：
1. **未见语义存在 AUROC 有没有提高？**  
   - 在 **构词划分 C1 (sit holdout)** 上，未见存在 AUROC 发生极显著提升（**0.5479 → 0.6206，提升 +0.0728**）。
   - 在其余划分上，未见存在 AUROC 未见明显提升（A1: 0.5065 → 0.4946, A2_alt: 0.5240 → 0.5016, A3: 0.6139 → 0.6032, C2_alt: 0.5474 → 0.5107）。
2. **Seen-Unseen Gap 有没有缩小？**  
   - **C1 划分显著收敛**：Gap 由 **0.2054 缩减至 0.1237**，实现 **Gap 恢复 +0.0817**。
   - 动作轴（A1, A2_alt, A3）整体 Gap 基本持平或微幅拉大（均值 Gap 由 0.2288 → 0.2436）。
3. **Gap 缩小的性质判定（是否由 Seen 崩溃导致？）**  
   - 在 C1 上，Seen AUROC 保持优异（0.7533 → 0.7443，仅微调 -0.0090），同视频未见配对准确率（Matched PairAcc）由 **55.56% 跃升至 65.28%（+9.72%）**，确认属于真实的泛化能力提升。

## 4. 关键科学发现与机制审判

### 发现 1：动作轴（Action）与构词轴（Composition）存在显著的机制不对称性
- **构词泛化（C1）显著缓解 (CASE A)**：
  当动作本身已知（`sit` 已在训练集中出现），但在测试时与未见物体（`chair` / `couch` / `bed`）形成新组合时，DQ-CGP 候选细化模块能够有效通过上下文基元绑定解耦文本与视频线索，使未见存在判别准确率（PairAcc）从 55.56% 大幅跃升至 65.28%，未见存在 AUROC 达到 0.6206，退化 Gap 缩减 40%。
- **动作动词泛化（A1, A2_alt）难以通过候选细化缓解 (CASE C)**：
  当动词语义本身未在训练集中见过（如 A1 的 `put` / `take`，A2 的 `drink` / `pour`），DQ-CGP 虽未损害模型，但亦未能缓解存在感知退化（Unseen AUROC 徘徊在 0.49~0.50 的随机水平）。这表明动作谓词的未见性属于更高层级的特征域漂移，无法单凭时序候选框与词级别的路由组合来恢复。

### 发现 2：候选细化在未见时序定位上表现出独立正增益 (CASE D - A3)
- 在 **A3 (run / walk)** 上，尽管存在判断 AUROC 未见明显改变，但 DQ-CGP 对未见事件的时序定位精度出现了极大飞跃：
  - $U^+$ raw R1@0.5 由 **46.88% 提升至 56.25%（+9.38%）**。
  - $U^+$ gated R1@0.5 由 **34.38% 提升至 44.27%（+9.89%）**。
  - 这证实了 DQ-CGP 的确学到了更具时序辨别力的候选特征，实现了对真实存在事件的高精度边界回归，但由于存在头（Existence Head）基于全视频均值池化，未见动作的全局语义不确定性依然阻碍了二值拒绝决策。

### 发现 3：官方全量测试指标对照保持稳健
在官方全测试集指标上，DQ-CGP (v3) 保持了极佳的性能水平：
- A1: 官方测试 mAP 由 36.91% 提升至 **38.34% (+1.43%)**，G-mIoU@1 由 35.01% 提升至 **36.72% (+1.71%)**。
- 5 组划分的官方全集整体指标均与基线持平或微幅更优，证明了 DQ-CGP v3 稀疏路由与关系约束的稳定性（未发生路由器崩塌或训练发散）。

## 5. 规范与严谨性声明 (Plan.md Section 20)

严格按照 `plan.md` 第二十条守则进行科学结论陈述，不进行过度解释：
1. **可以陈述的结论**：
   在冻结的 Charades-STA 语义存在基准上，DQ-CGP (v3) 表现出强烈的**轴依赖性**：它在**构词新颖性划分（C1）上显著缓解了 FlashVTG-GMR 的 seen→unseen 退化（达到 CASE A）**，并在动作划分（A3）上显著增强了未见时序定位能力（+9.4% R1@0.5）；但对于纯动作谓词的新颖性（A1/A2_alt），当前的候选细化并未提供存在感知的泛化缓解。
2. **不能声称的结论**：
   不能据此宣称“Event Binding 是导致退化的唯一根本机制”，亦不能宣称“Event Binding 对动作无效”；只能严谨表述为：当前的 DQ-CGP v3 候选细化架构对构词重组有效，但在全局未见动词的跨语义存在判决上仍受限于骨干网络文本-视觉联合表征的固有泛化瓶颈。
